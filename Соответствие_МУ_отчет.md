(Многопрофильный колледж ТИУ, сост. Ю.Н. Мухина, Тюмень, ТИУ, 2024)

**Что сверялось**
- отчёт: `Отчёт по УП.01 Куштаров.docx` (13 страниц, 156 абзацев, 3 рисунка, 3 таблицы) — редакция из коммита `be8614c`;
- методические указания: `МУ по  оформлению ОТЧЕТОВ о практике.docx`, 536 абзацев, 27 с. — файл из коммита `d5510c4` (загружен 23.11.2026).

## 11. План доработки по приоритетам

**Приоритет 1 — без этого отчёт не примут**

1. Штамп и нумерация: разбить на секции по разделам, форму 2 — на первую страницу каждого раздела, форму 2а — на последующие; в штампе «Лист» = номер в разделе, «Листов» = число листов раздела; убрать номер с содержания; исправить «Листов 15» → фактическое число.
2. Заголовки: убрать полужирный, выровнять по ширине с абзацным отступом 1,25 см, номера без точки (`1`, `2` …), «Список литературы» → «Список использованных источников».
3. Ссылки на источники: расставить [1]–[8] в тексте по упоминаниям (нормативные — в разделе 1, литература — в разделах 2–6, таблица 3 и т. д.).
4. Шифр в штампе: привести к виду `15.01.37.2845.2026.УП.01` (или иной вид индекса — уточнить у руководителя).

**Приоритет 2 — структура и библиография**

5. Добавить приложения (или согласовать с руководителем, что они сдаются отдельно): дневник, индивидуальное задание, аттестационный лист, характеристика; внести их в содержание.
6. Список источников: переименовать раздел, сгруппировать (нормативные документы → учебные/методические издания → электронные ресурсы), оформить по ГОСТ 7.0.100-2018, даты обращения — в виде «(дата обращения: 11.11.2026)».
